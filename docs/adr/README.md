# ADR Index

## Numbering policy

- **Root `docs/adr/NNN-*.md`** — cross-component architecture decisions.
  Cite as "ADR-008", "ADR-012", etc.
- **`catalog/docs/adr/NNN-*.md`** — catalog-internal decisions.
  Cite as "catalog-ADR-001", "catalog-ADR-002", etc.
- Numbers are assigned only at acceptance. Pending decisions are referred
  to by topic label: **"ADR candidate: <topic>"** (e.g. "ADR candidate:
  pydantic-boundary"). Two different decisions must not share a number.
