## 1. Definicja i zastosowanie

**Blaty ABS Square Edge** to nowoczesna wersja blatów roboczych charakteryzująca się prostą krawędzią wykończoną 1,5 mm obrzeżem ABS. Dzięki prostej, czystej linii ta forma blatów jest doskonała do nowoczesnych lub minimalistycznych projektów kuchni.

### Zastosowanie:
- Blaty kuchenne (nowoczesne, minimalistyczne)
- Blaty stołowe
- Blaty biurek
- Lady sklepowe

---

## 2. Budowa przekroju (str. 55)

### Format 635 mm:
```
     ←───────────── 635 mm ─────────────→
    ┌────────────────────────────────────┐
    │  Laminat 0,5-0,8 mm               │  ← góra
    ├────────────────────────────────────┤
    │  Płyta wiórowa                    │  ← rdzeń
    ├────────────────────────────────────┤
    │  Folia Finish (lakier akrylowy)   │  ← spód
    └────────────────────────────────────┘
    ↑ Obrzeże Unoflex (lewy)    ↑ Obrzeże ABS 1,5 mm (prawy)
```

### Format 1200 mm:
```
     ←───────────── 1200 mm ─────────────→
    ┌────────────────────────────────────┐
    │  Laminat 0,5-0,8 mm               │  ← góra
    ├────────────────────────────────────┤
    │  Płyta wiórowa                    │  ← rdzeń
    ├────────────────────────────────────┤
    │  Folia Finish (lakier akrylowy)   │  ← spód
    └────────────────────────────────────┘
    ↑ Obrzeże ABS 1,5 mm (lewy)    ↑ Obrzeże ABS 1,5 mm (prawy)
```

### Warstwy (od dołu do góry):

| Warstwa | Materiał | Funkcja |
|---------|----------|---------|
| **1. Spód** | Folia Finish (zabezpieczona lakierem akrylowym) | Ochrona spodu, wykończenie |
| **2. Rdzeń** | Płyta wiórowa | Główny materiał nośny |
| **3. Górna** | Laminat 0,5-0,8 mm | Warstwa dekoracyjna i ochronna |
| **4. Krawędź** | Obrzeże ABS 1,5 mm | Wykończenie krawędzi (proste, R=1,5 mm) |

### Kluczowe cechy konstrukcji:

1. **Prosta krawędź** - kąt prosty, R = 1,5 mm (nie zaokrąglona jak postformed)
2. **Obrzeże ABS 1,5 mm** - cieńsze niż w meblach (2-3 mm)
3. **Folia Finish** - spód zabezpieczony lakierem akrylowym
4. **Dwa formaty** - 635 mm (jedna krawędź ABS) i 1200 mm (obie krawędzie ABS)

## 3. Profile blatów (str. 55)

### Format 635 mm (jedna krawędź ABS)

```
     ←───────────── 635 mm ─────────────→
    ┌────────────────────────────────────┐
    │  ╭──────────────────────────────╮  │
    │  │                              │  │  R = 1,5 mm
    │  │        Płyta wiórowa         │  │
    │  │                              │  │
    │  ╰──────────────────────────────╯  │
    └────────────────────────────────────┘
              ↑ krawędź ABS (prosta)
```

- **Szerokość**: 635 mm
- **Krawędź**: jedna strona wykończona obrzeżem ABS
- **Zastosowanie**: blaty przy ścianie

### Format 1200 mm (obie krawędzie ABS)

```
     ←───────────── 1200 mm ─────────────→
    ┌────────────────────────────────────┐
    │  ╭──────────────────────────────╮  │
    │  │                              │  │  R = 1,5 mm
    │  │        Płyta wiórowa         │  │
    │  │                              │  │
    │  ╰──────────────────────────────╯  │
    └────────────────────────────────────┘
              ↑ obie krawędzie ABS (proste)
```

- **Szerokość**: 1200 mm
- **Krawędź**: obie strony wykończone obrzeżem ABS
- **Zastosowanie**: blaty wyspowe, lady sklepowe

## 7. Uwagi techniczne

### Obrzeża dostępne w dwóch wersjach:

#### Spander by Schilsner:
- Profesjonalne rozwiązanie do wykańczania krawędzi
- Prosta krawędź o minimalnej fazie
- Powierzchnia wzmocniona specjalnym procesem technologicznym
- Rozmiar: 42/1,2 mm, w rolkach 25 lub 50 mb

#### REHAU Interior Solutions:
- Sprawdzone rozwiązanie do trwałego i estetycznego zabezpieczania krawędzi
- Precyzyjne wykończenie krawędzi prostych
- Dokładne dopasowanie do laminatu
- Rozmiar: 43/1,5 mm, w rolkach 5 i 25 mb

### Różnice vs Postformed:
| Cecha | ABS Square Edge | Postformed |
|-------|-----------------|------------|
| Krawędź | **Prosta (R=1,5mm)** | Zaokrąglona (R=3,3mm) |
| Obrzeże | **ABS 1,5 mm** | Unoflex (postformed) |
| Grubość | 38 mm | 38 mm |
| Szerokości | 635, 1200 mm | 600, 900, 1200 mm |
| Styl | **Nowoczesny, minimalistyczny** | Klasyczny |
