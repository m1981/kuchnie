# SketchUp macOS — Navigation Cheatsheet

(View movement only — no geometry editing)

## Mouse Controls

| Action                               | Control                                   |
| ------------------------------------ | ----------------------------------------- |
| Orbit                                | Middle mouse button (hold + drag)         |
| Pan (move screen left/right/up/down) | Shift + Middle mouse button (hold + drag) |
| Zoom in/out                          | Scroll wheel                              |
| Zoom to a point                      | Scroll wheel toward/away from cursor      |

## Keyboard Shortcuts (Navigation Tools)

| Tool         | Shortcut  |
| ------------ | --------- |
| Orbit        | O         |
| Pan          | H         |
| Zoom         | Z         |
| Zoom Extents | Shift + Z |

## Panning (Move Screen Right/Left/Up/Down)

**Fastest method (no tool switch needed):**
Shift + Middle mouse button, hold and drag.

- Drag right → view shifts left
- Drag left → view shifts right
- Drag up → view shifts down
- Drag down → view shifts up

**Keyboard + mouse method:**

1. Press H (Pan tool)
2. Click + drag with left mouse button
3. Press Esc to exit

**No middle mouse button / trackpad:**

- Press H, then click-drag with left button, or
- Two-finger scroll (depends on trackpad/OS settings)

## Quick Reference

| Tool                        | Function             |
| --------------------------- | -------------------- |
| Middle-click + drag         | Orbit (rotates view) |
| Shift + Middle-click + drag | Pan (slides view)    |
| Scroll wheel                | Zoom in/out          |

## Notes

- Orbit, Pan, and Zoom work at any time, regardless of active tool.
- Esc cancels Orbit/Pan/Zoom and returns to the previous tool.
- SketchUp does not assign default keys to standard views (Top, Front, Iso, etc.) — these can be added manually under SketchUp → Preferences → Shortcuts.
