# LEGRABOX + BLUMOTION — Specyfikacja techniczna

## 1. Wymiary boków szuflad LEGRABOX

| Typ   | Wysokość boku (mm) | Zastosowanie                   |
| ----- | ------------------ | ------------------------------ |
| **N** | 66.5               | Sztućce, drobiazgi, przyprawy  |
| **M** | 90.5               | Garnki, patelnie, pojemniki    |
| **K** | 128.5              | Duże garnki, miski             |
| **C** | 177.0              | Produkty sypkie, duże naczynia |
| **F** | 241.0              | Specjalne zastosowania         |

## 2. Nominalne długości prowadnic (mm)

| Klasa obciążenia | Długości                               |
| ---------------- | -------------------------------------- |
| **40 kg**        | 270, 300, 350, 400, 450, 500, 550, 600 |
| **70 kg**        | 450, 500, 550, 600, 650                |

**Uwaga:** Minimalna głębokość wewnętrzna szafki = nominalna długość + 3mm

## 3. Wymiary cięcia dna i tyłu szuflady

### Dno szuflady (płyta 16mm):

```
Szerokość = Szerokość wewnętrzna szafki - 35mm
Długość = Nominalna długość - 10mm (tył z płyty)
Długość = Nominalna długość - 21mm (tył stalowy)
```

### Tył szuflady (płyta 16mm):

```
Szerokość = Szerokość wewnętrzna szafki - 38mm
Wysokość = 148mm (standard)
```

## 4. Mocowanie profilu kab. do boku szafki

### Pozycje otworów (System 32):

```
Od krawędzi przedniej: 37mm
Pierwszy otwór od dna: 9mm
Rozstaw pionowy: 32mm
Średnica otworu: ∅5mm (lub ∅2.5mm dla wstępnych nawierceń)
```

### Typowe pozycje dla prowadnicy 500mm (40kg):

```
Od przodu: 37mm
Od dołu: 9, 41, 73, 105, 137, 169, 201, 233, 265, 297, 329, 361, 393, 425, 457mm
```

## 5. BLUMOTION — Specyfikacja

### Zintegrowany BLUMOTION w LEGRABOX:

- **Mechanizm:** Zintegrowany w prowadnicy (nie wymaga dodatkowych nawierceń)
- **Siła domyku:** Automatycznie regulowana
- **Prędkość domyku:** Stała, niezależna od siły pchnięcia
- **Temperatura pracy:** -10°C do +60°C

### Kombinacje z innymi technologiami:

| Technologia      | Kompatybilność                               |
| ---------------- | -------------------------------------------- |
| BLUMOTION        | ✓ Standard                                   |
| SERVO-DRIVE      | ✓ Opcja (elektryczny otwieracz)              |
| TIP-ON BLUMOTION | ✓ Opcja (mechaniczny otwieracz + soft-close) |
| TIP-ON           | ✓ Opcja (mechaniczny otwieracz)              |

## 8. Współpraca z innymi okuciami Blum

### CLIP top BLUMOTION (zawiasy):

- Montaż w System 32
- Puszka ∅35mm w froncie
- Rozstaw śrub: 45mm (Blum)

### AVENTOS (podnośniki frontów górnych):

- Montaż w System 32
- Kompatybilny z LEGRABOX w szafkach dolnych

### AMBIA-LINE (organizacja szuflad):

- Wkładki dopasowane do LEGRABOX
- Dostępne w kolorach: biały, jedwabisty szary, antracyt, stal nierdzewna
