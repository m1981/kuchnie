# Curated Kitchens — Kronospan 2026

> **Purpose**: Seed the `curated_kitchens` table in the configurator.
> Each setup is a complete, buildable material specification using **only** Kronospan products.
> Follows the 6-step state machine: front → carcass → worktop → edge → side panel → plinth (+ splashback).

---

## How to read each setup

| Field | Meaning |
|---|---|
| **front** | Product line + decor code + structure (the visual identity) |
| **carcass** | Interior of cabinets (usually K110 — Kronospan's standard white corpus) |
| **worktop** | Collection (Post-formed / ABS Square Edge / Slim Line / FitLine) + decor |
| **edge** | ABS edge banding code (Schilsner or Rehau) |
| **side_panel** | Visible cabinet sides — same as front (premium) or same as carcass (budget) |
| **plinth** | Kickboard — same as carcass, front, or contrasting |
| **splashback** | Wall panel between worktop and wall cabinets |

## Design decisions & rationale

### Why K110 as universal carcass?
K110 (Biały Korpusowy) is Kronospan's dedicated corpus white. It's:
- The cheapest white in the range (group I — single decor, optimized for cost)
- Available in all thicknesses (12, 16, 18mm) Express 24h
- RAL 9016 — universal white that works with every front color
- Using matching front decor as carcass is possible but 2-3x more expensive

### Why Slim Line for modern, Post-formed for classic?
- **Slim Line (12mm)**: Ultra-thin, monochromatic, no edge banding needed → reads as "contemporary, premium, minimal"
- **Post-formed (38mm)**: Rounded R=3.3mm edge, chunky profile → reads as "traditional, substantial, kitchen-like"
- **ABS Square Edge (38mm)**: Straight edge, R=1.5mm → the middle ground, works with everything

### Why white marble worktops with colored fronts?
White marble-look (Calacatta, Biały Marmur Lodowy) is the universal "safe" worktop for colored fronts because:
- It provides maximum contrast (colored front pops against white)
- It's the most popular worktop category in Poland
- It pairs with virtually any splashback
- It doesn't compete with the front for attention

### Why concrete worktops with concrete fronts works (3A)?
Normally you'd avoid "too much of the same material." But in industrial style, the deliberate overuse of concrete IS the aesthetic. The trick is varying the shade (black concrete front + light grey concrete worktop) so there's still visual hierarchy.
