## 3. Porównanie krawędzi

### Post-formed (R = 3,3 mm)
```
    ╭────────────────────────────╮
    │                            │  ← zaokrąglona krawędź
    │        Płyta wiórowa       │
    │                            │
    ╰────────────────────────────╯
```
- **Materiał**: Unoflex (elastyczne obrzeże)
- **Promień**: R = 3,3 mm
- **Zalety**: Gładka, ciągła krawędź, odporna na wilgoć
- **Zastosowanie**: Klasyczne kuchnie

### FitLine (R = 3,3 mm)
```
    ╭────────────────────────────╮
    │                            │  ← zaokrąglona krawędź
    │        Płyta wiórowa       │
    │                            │
    ╰────────────────────────────╯
```
- **Materiał**: Unoflex (elastyczne obrzeże)
- **Promień**: R = 3,3 mm
- **Zalety**: Cieńsza konstrukcja (18 mm)
- **Zastosowanie**: Nowoczesne kuchnie, stoły

### ABS Square Edge (R = 1,5 mm)
```
    ┌────────────────────────────┐
    │                            │  ← prosta krawędź
    │        Płyta wiórowa       │
    │                            │
    └────────────────────────────┘
```
- **Materiał**: ABS 1,5 mm
- **Promień**: R = 1,5 mm (praktycznie kąt prosty)
- **Zalety**: Nowoczesny, minimalistyczny wygląd
- **Zastosowanie**: Nowoczesne, minimalistyczne kuchnie

### Slim Line (naturalna)
```
    ┌────────────────────────────┐
    │                            │  ← naturalna krawędź
    │      Płyta kompaktowa      │
    │                            │
    └────────────────────────────┘
```
- **Materiał**: Brak (naturalna krawędź płyty)
- **Promień**: Brak (prosta)
- **Zalety**: Ultra nowoczesny, monochromatyczny
- **Zastosowanie**: Ultra nowoczesne kuchnie, łazienki

## 8. Rekomendacje

### Dla kuchni klasycznej:
→ **Post-formed** (38 mm, R=3,3mm, 40 dekorów)

### Dla kuchni nowoczesnej:
→ **ABS Square Edge** (38 mm, prosta krawędź, 26 dekorów)

### Dla kuchni minimalistycznej:
→ **Slim Line** (12 mm, naturalna krawędź, monochromatyczna)

### Dla wyspy kuchennej (waterfall):
→ **Slim Line** (12 mm, efekt waterfall)

### Dla łazienki:
→ **Slim Line** (12 mm, wodoodporna)

### Dla budżetu:
→ **Post-formed** lub **FitLine** (najniższa cena)
