## Obrzeże — Rehau (nie Schilsner!)

Kolekcja Emporio używa obrzeży **Rehau**, nie Schilsner.

Wzorzec kodowania: `XXXXX` + sufiks `Z` lub `W`

Przykłady:
- 2359Z (Carbon Fumo)
- 4907W (Abaco Incanto)
- 4867W (Inca)

> Rehau = premium edgebanding, wyższa jakość niż standard Schilsner.
