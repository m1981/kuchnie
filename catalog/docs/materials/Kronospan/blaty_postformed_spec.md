## Analiza kolekcji (strony 1, 4, 9 z katalogu)

## 1. Definicja i zastosowanie

**Blaty Post-formed** to blaty robocze produkowane przez formowanie (gięcie) laminatu HPL na gorąco na krawędzi blatu. Proces ten tworzy gładką, ciągłą krawędź bez widocznych szwów.

### Zastosowanie:
- Blaty kuchenne
- Blaty stołowe
- Blaty biurek
- Lady sklepowe

---

## 2. Budowa przekroju (str. 43)

```
┌─────────────────────────────────────────────────────┐
│  Obrzeże Unoflex  │  HPL dekoracyjny  │  Pasek HDF  │  ← góra (powierzchnia robocza)
├─────────────────────────────────────────────────────┤
│                                                     │
│                   Płyta wiórowa                      │  ← rdzeń (nośny)
│                                                     │
├─────────────────────────────────────────────────────┤
│              Papier przeciwprężny                    │  ← spód (ochrona)
└─────────────────────────────────────────────────────┘
```

### Warstwy (od dołu do góry):

| Warstwa | Materiał | Funkcja |
|---------|----------|---------|
| **1. Spód** | Papier przeciwprężny | Chroni przed odkształcaniem się laminatu |
| **2. Rdzeń** | Płyta wiórowa | Główny materiał nośny, zapewnia sztywność |
| **3. Górna** | HPL dekoracyjny | Warstwa dekoracyjna i ochronna (odporna na zarysowania, plamy) |
| **4. Wzmocnienie** | Pasek HDF | Wzmacnia przednią krawędź, zapobiega pękaniu laminatu |
| **5. Krawędź** | Obrzeże Unoflex | Wykończenie krawędzi frontowej, zaokrąglenie R=3.3mm |

### Kluczowe cechy konstrukcji:

1. **Laminat HPL na gorąco** - laminat jest formowany (gięty) na gorąco na krawędzi, tworząc ciągłą powierzchnię
2. **Pasek HDF** - wzmocnienie pod laminatem na krawędzi frontowej dla wytrzymałości
3. **Obrzeże Unoflex** - elastyczne obrzeże, które tworzy gładkie zaokrąglenie R=3.3mm
4. **Papier przeciwprężny** - na spodzie równoważy naprężenia laminatu górnego

## 3. Profile blatów (str. 43)

### Profile U (jedna krawędź wykończona)

```
     ←───────────── 600 mm ─────────────→
    ┌────────────────────────────────────┐
    │  ╭──────────────────────────────╮  │
    │  │                              │  │  R = 3.3 mm
    │  │        Płyta wiórowa         │  │
    │  │                              │  │
    │  ╰──────────────────────────────╯  │
    └────────────────────────────────────┘
              ↑ krawędź postformed
```

- **Szerokość**: 600 mm
- **Krawędź**: jedna strona wykończona (frontowa)
- **Zastosowanie**: blaty przy ścianie (z jednej strony widoczna krawędź)

### Profile U-U (obie krawędzie wykończone)

```
     ←───────────── 900/1200 mm ─────────────→
    ┌──────────────────────────────────────────┐
    │  ╭────────────────────────────────────╮  │
    │  │                                    │  │  R = 3.3 mm
    │  │          Płyta wiórowa             │  │
    │  │                                    │  │
    │  ╰────────────────────────────────────╯  │
    └──────────────────────────────────────────┘
              ↑ obie krawędzie postformed
```

- **Szerokości**: 900 mm, 1200 mm
- **Krawędź**: obie strony wykończone (postformed)
- **Zastosowanie**: blaty wyspowe, lady sklepowe (widoczne z obu stron)
